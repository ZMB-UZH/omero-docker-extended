# Code of Conduct

## Purpose

This repository is a technical project for a Dockerized OMERO deployment and
related OMERO.web plugins. Project discussion should stay respectful,
evidence-based, and focused on improving the software, documentation, security,
or operational reliability.

## Expected Behavior

- Treat other participants with professional respect.
- Keep feedback specific, actionable, and grounded in reproducible evidence.
- Assume production and research-data safety matter when proposing changes.
- Use private vulnerability reporting for security-sensitive information.
- Respect project-maintainer decisions about project scope, verification requirements,
  and operational risk.

## Unacceptable Behavior

- Harassment, threats, insults, or discriminatory language.
- Publishing private information, credentials, secrets, exploit details, or
  host-specific deployment data.
- Derailing issues or pull requests with unrelated arguments.
- Repeatedly bypassing templates, security guidance, or maintainer direction.
- Any behavior that creates an unsafe or hostile project environment.

## Reporting

Conduct concerns may be reported through GitHub's content-reporting tools when
available. Security issues must use the private vulnerability path documented in
[SECURITY.md](SECURITY.md):
<https://github.com/ZMB-UZH/omero-docker-extended/security/advisories/new>.
If GitHub's reporting tools are unavailable, contact the repository maintainer
through a non-public channel.

Reports are reviewed with attention to safety, context, and project impact.
Possible actions include clarification, comment editing requests, conversation
locking, issue or pull request closure, interaction limits, or escalation to
GitHub Support.

## Scope

This code of conduct applies to repository issues, pull requests, discussions,
reviews, and other project spaces controlled by the repository maintainer.
