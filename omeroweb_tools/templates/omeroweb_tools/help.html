Tools help

Use the controls shown below to search OMERO data and opt-in universal metadata from one page.

Run a search

  • Type terms, choose an indexed scope, and optionally set dates.
  • All searchable sources merges OMERO and universal metadata matches.
  • Use Clear to empty the search fields and current results.

Universal metadata index

  • Turn indexing on to include metadata OMERO does not normally search.
  • Click Refresh index after imports or metadata edits.
  • The setting and indexed data are scoped to your user account.

Read results

  • Open image, project, or dataset links directly in OMERO.web.
  • Previews, acquisition values, and channels appear when available.

Saved search queries

  • Name the current search and click Save.
  • Saved searches belong to your user account.

Troubleshooting

  • Check the selected indexed scope.
  • Refresh the universal metadata index after imports or edits.
  • Use fewer terms if the query is too narrow.
  • Confirm that you can still view the image in OMERO.web.
